DiaAI

Intelligent Diabetes Prediction System

Project Overview

DiaAI is a Flask-based machine learning application designed to predict diabetes risk using patient-related input features.

Machine Learning Model

The application uses a Decision Tree Classification model trained on diabetes-related data.

Input Features

Pregnancies
Glucose
Blood Pressure
Skin Thickness
Insulin
BMI
Diabetes Pedigree Function
Age

Technology Stack

Python Flask Scikit-learn NumPy HTML CSS JavaScript
